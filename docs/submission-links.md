## Что доступно без установки

Документ, сводка, снимок интерфейса, выполненные ячейки ноутбука, JSON-расчёты и CSV кампании читаются в GitHub. Сохранённые результаты не требуют запущенного сервера.

## Как проверить интерактивность

Клонировать репозиторий, установить Python 3.12 и выполнить `sh prototype/start.sh`. Адрес `http://127.0.0.1:8765` — локальный адрес после запуска, а не публичная ссылка на размещённый сервис.

В ноутбуке есть вызовы сохранённых моделей и расчётов. Код можно исполнить повторно; инструкции и зависимости включены.
