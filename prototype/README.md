# Gate 3: прототип удержания РКО

[Главная страница для проверяющего](../README.md) · [Краткая сводка результатов](../docs/results.md)

## Запуск

Одна команда из корня проекта:

```sh
sh prototype/start.sh
```

Она создаёт окружение, устанавливает зависимости, пересоздаёт данные и модели, запускает регрессионные тесты и поднимает [локальную демо](http://127.0.0.1:8765). Требуется Python 3.12; интернет нужен при первой установке библиотек. Данные UCI и обученные модели уже включены. Прототип не вызывает внешние сервисы и не отправляет клиентские сообщения. Завершение сервера — Ctrl+C. Если порт занят: `PORT=8766 sh prototype/start.sh`.

Для быстрого просмотра сохранённого результата, если зависимости установлены:

```sh
python prototype/app.py
```

Пересчёт без сервера: `python prototype/run.py`. Проверки: `python -m unittest discover -s prototype/tests -v`. Ноутбук с выполненными ячейками: [demo.ipynb](demo.ipynb); для повторного исполнения в Jupyter нужно выбрать ядро из того же окружения. Он использует сохранённые модели, выполняет новые прогнозы и показывает пять сценариев.

## Метод и происхождение

Основной набор: 50 тыс. разных клиентов, 24 месяца входящих оборотов, один срез на клиента. Обучение — июль–сентябрь 2024; калибровка — февраль–март 2025; тест — сентябрь 2025. Между частями выдерживается буфер зрелости метки 120 дней. Фильтры допуска применяются до обучения, оценки и клиентского прогноза. Вероятности закрытия и тихого оттока калибруются отдельно на калибровочном периоде; для объединения используется дополнительная изотоническая калибровка суммы исходных скоров. Идентификаторы не являются признаками.

Панель, воздействия, исходы кампаний, 200 карточек и пять интервью-сценариев созданы для учебной симуляции. Истинные эффекты лежат отдельно от признаков и используются только при оценке. Контрольные модели четырёх ветвей обучаются по наблюдаемому результату случайного назначения. Дата закрытия, таргеты, назначение воздействия и ограничения не входят в признаки риска. SHAP относится к логарифму шансов исходной модели тихого оттока; он не объясняет причинный эффект оффера.

Отдельный публичный бенчмарк: [Iranian Churn, UCI](https://archive.ics.uci.edu/dataset/563/iranian+churn+dataset), DOI [10.24432/C5JW3Z](https://doi.org/10.24432/C5JW3Z), CC BY 4.0; скачан 25.10.2026. 3 150 обезличенных наблюдений из телекома. Исходный CSV сохранён без изменений; URL, лицензия и SHA-256 находятся в `data/public/iranian_churn.source.json`. Признаки агрегированы за первые девять месяцев, исход — к концу двенадцатого. Одинаковые векторы признаков не пересекают обучение и тест; интервалы получены повторной выборкой групп. Это не календарная проверка и не оценка удерживающих действий. `Status`, `Customer Value`, возраст и возрастная группа исключены.

KKBox не скачивался: на публичной странице не доступны строки данных без отдельного доступа к соревнованию. UCI добавлен как независимая проверка классификации; он не закрывает обещанную проверку временной нарезки на KKBox. Ограничения сайтов с отзывами не обходились.

Конфигурация тарифов в `core.py` — сценарная: базовая плата 490/1 990/4 990 ₽ из Gate 2, число включённых платежей и комиссии заданы для теста. Пакет: 990 ₽/мес, 40 дополнительных платежей, три месяца без оплаты. Годовая оплата: −17% базовой платы. Проверяются полная цена за первый год и регулярная цена после промо. Актуальные рыночные тарифы не утверждаются.

## Файлы и воспроизводимость

`core.py` — генератор, модели, фильтры, калькулятор и отбор. `run.py` — эксперимент и расчёт результатов. `app.py` и `demo.html` — локальная работающая демо. `tests/test_prototype.py` — проверки происхождения признаков, временных границ, отсутствия запрещённых полей, допуска, бюджета, контроля и денежной арифметики.

`data/monthly_panel.npz` — 1,2 млн месячных наблюдений; `snapshots.csv.gz` — срезы и метки; `simulation_truth.csv.gz` — отдельный эталон эффектов. `models/bundle.pkl` — собственные модели этого проекта. Загружать следует только этот созданный локально файл: формат pickle выполняет код при чтении чужого файла. Параметры моделей фиксированы до проверки теста, seed 20261025. Состав и версии — `results/manifest.json`. Время исполнения зависит от машины.

Одиннадцать структурных тестов проверяют корректность программы, включая согласованность вероятностей двух таргетов и их объединения. Девять сценариев C4 проверяют поведение модели; неуспешный сценарий сохраняется в отчёте и не маскируется под программную ошибку.
